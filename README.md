## Web OS 1.1
This is a web OS project inspired by the concept of a media library. it was still wholly unfinished but I already have bigger ideas for it; I plan to link it to my personal website as my blog/yapp page so
each blog would be it's own app. In addition to blogs its also going to have media reviews like the one for shadow slave. The name Ikaiwe os comes from the Yoruba word for school/library. I am proud of it but
disappointed because I could’ve done so much more work on it.
